# Questions about licensing

## Is a white-label licence the same as owning LabFlow?

No. A licence is a hosted, branded deployment. The code stays with the LabFlow team until a buyout, and the buyout is a separate purchase.

## Can I run it on my own servers?

Not with a licence: we host it. After a [buyout](https://labflow.aoneahsan.com/white-label/buyout/) the code is yours to run wherever you choose, and hosting it becomes your work rather than ours.

## Is there an iOS app?

LabFlow is not published on the App Store. The iOS build is delivered when you provide or fund an Apple developer account.

## Does a licence make my laboratory accredited?

No. LabFlow is not a medical device and holds no accreditation. Whoever uses it for patients, under any name, is responsible for every registration, accreditation and approval its jurisdiction requires, and for the clinical decisions made with it.

## Can I ask for changes?

Yes, as [custom work](https://labflow.aoneahsan.com/white-label/custom-work/). Each piece is quoted on its own and nothing starts before you agree to the quote.

## How is a licence checked?

On the [verify page](https://labflow.aoneahsan.com/verify-license/), by key or by domain. See [Verifying a licence](./verify-a-licence.md).
